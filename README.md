🚀 AI Nexus: 실시간 기술 트렌드 분석기

AI Nexus는 현대적인 웹 기술을 사용하여 현재 가장 주목받는 IT 트렌드를 시각적으로 분석하고 소개하는 React 기반 웹 애플리케이션입니다. 사용자에게 몰입감 있는 분석 경험을 제공하기 위해 다양한 애니메이션과 세련된 UI를 특징으로 합니다.

🔗 Live Demo
URL: http://mybucket-20263579.s3-website-us-east-1.amazonaws.com/

Hosting: AWS S3 (Static Website Hosting)

✨ 핵심 기능 (Key Features)
1. 실시간 데이터 스캔 시뮬레이션
  Interactive Scanning: '분석 시작' 버튼 클릭 시, 시각적인 레이저 스캔 애니메이션과 프로그레스 바를 통해 데이터 분석 과정을 생동감 있게 전달합니다.
  Dynamic State: React의 상태 관리를 통해 대기, 분석 중, 완료 단계를 직관적으로 화면에 구현했습니다.

2. 지능형 트렌드 큐레이션
   Random Insights: 미리 정의된 최신 기술 데이터베이스에서 랜덤하게 트렌드를 추출하여 사용자에게 매번 새로운 통찰을 제공합니다.
   Core Topics: Agentic AI, Spatial Computing, Green Software 등 2026년 주요 기술 키워드를 포함합니다.

3. 프리미엄 사용자 경험 (UX)
   Glassmorphism UI: 반투명한 배경과 블러 효과를 결합하여 깊이감 있는 세련된 디자인을 완성했습니다.
   Motion Design: CSS Keyframes를 활용한 배경 글로우 애니메이션과 슬라이드 업 효과로 사용자 몰입도를 높였습니다.
